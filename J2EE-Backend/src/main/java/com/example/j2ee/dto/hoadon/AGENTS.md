# dto/hoadon

## Purpose
Payloads for hóa đơn (invoice) management: create/update/cancel requests, list and detail responses, and the invoice statistics summary.

## Key Files
| File | Description |
|------|-------------|
| `CreateHoaDonRequest.java` | Create payload: `maDonHang`, `soHoaDon`, `ngayHachToan`, `tongTien`, `thueVAT` (default 0), `nguoiLap`, `ghiChu`. |
| `UpdateHoaDonRequest.java` | Update payload: `maHoaDon`, accounting date, VAT, issuer, note, status. |
| `HuyHoaDonRequest.java` | Cancellation: `maHoaDon`, `lyDoHuy`, `nguoiThucHien`. |
| `HoaDonResponse.java` | Invoice row: numbers, amounts (`tongTien`, `thueVAT`, `tongThanhToan`), status, customer contact, order total. |
| `HoaDonDetailResponse.java` | Invoice detail including PNR, timestamps and the linked order status. |
| `HoaDonThongKeDTO.java` | Invoice statistics: issued/cancelled/adjusted counts plus revenue and VAT totals. |

## For AI Agents

### Working In This Directory
- `soHoaDon` is the human-readable invoice number and is generated by the service, not by the client.
- Invoice status values: `DA_PHAT_HANH`, `DA_HUY`, `DIEU_CHINH`.
- `thueVAT` defaults to zero and is added on top of `tongTien` to produce `tongThanhToan` — keep the arithmetic in one place.

### Testing Requirements
- Cover VAT and total arithmetic in a service test; the Jasper PDF template is checked by `src/test/java/com/example/j2ee/controller/InvoiceReportTemplateTest.java`.
- Verify the cancel flow releases the invoice number.

### Common Patterns
- Money is `BigDecimal`; `ngayHachToan` is a `LocalDate`, `ngayLap` a `LocalDateTime`.
- Cancellation is a status change plus a reason and the acting staff member, not a delete.

## Dependencies

### Internal
- `../../service/HoaDonService.java` - invoice lifecycle.
- `../../service/JasperHoaDonService.java` - renders the invoice PDF from this data.

### External
- Jakarta Validation - constraints on the create/update payloads.
